# Applications

`recorder` fournit la capture locale Chromium et l'export JSON de demo-shop.
Depuis la racine : `pnpm capture` pour l'export seul, `pnpm demo` pour le pipeline.
`workbench` fournit l'interface locale, l'historique et l'orchestration : `pnpm dev`.
Voir [l'architecture](../docs/architecture.md).
